# Release notes — 1.0.1 (template, en-US)

Fill from the `## v1.0.1` section of `docs/CHANGELOG.md`, condensed to lines a
player would notice. Keep the two versions separate: Play is hard-capped at
**500 Unicode characters**, App Store Connect allows **4000**.

## Play — Release notes (≤ 500 chars)

Lead with what changed, one line each, no decision numbers:

```
What's new

• <the change a player notices, in their words>
• <…>

Fixes
• <the bug, described as the symptom, not the cause>
```

## App Store Connect — What's New in This Version (≤ 4000 chars)

Available from the second version onward. Same content, room to explain:

```
<One sentence on the theme of the release.>

New
• <feature> — <what it lets you do>

Improved
• <change> — <why it is better>

Fixed
• <symptom that no longer happens>
```

Both should agree; only the length differs.
