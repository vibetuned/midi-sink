## 1. What this is
A suminagashi (Japanese ink-marbling) MIDI/MPE visualizer and instrument: **midi-sink**. Shipped 1.0 across macOS/Windows/Linux/iOS/Android + a WebGPU marble web build; docs site live (operator book with live wasm demos, MIDI implementation chart, design notes, performance gallery). Reference hardware: ROLI Piano + Airwave, Expressive E Osmose, Roland Aerophone Brisa / Travel Sax, classic keyboards; plus the tablets' own touch/stylus MPE play surface.

## 2. Architecture pillars (violate none without a DECISIONS entry)
* **Option-2 pattern:** `libsumi` = headless C++20 core behind a pure C ABI (`sumi_core.h`: no STL/exceptions across it, three-state export macro, version-gated structs). Host shells own windows/MIDI-IO/UI: GLFW desktop, SwiftUI, Compose+JNI, JS/wasm. Shared host-side C++ (`hostmpe/`, pure-C header) serves the play surface on both tablets.
* **The engine is symplectic, not "fluid":** all deformations are closed-form inverse-lookup maps on a ping-pong RGBA16F coordinate field. **No Navier–Stokes solvers ever — exact NS *solutions* welcome** (Lamb–Oseen). Two operator classes, always declared: **exact** (det J = 1 at any magnitude: drop, tine, vortex profiles, pinch, ripple, swirl, scroll, torsion, Chladni, spark shear, Chirikov) and **sub-stepped displacement fields** (divergence-free field applied in ≤ a/4-style steps: wake, viscous multipole burst).
* **Field conventions:** parity ink phase (RGBA16F-safe), aux = drop counter (rebased on paper dip), one y-down texture space — backend flips live ONLY in the final composite + print path (§4.6; cross-backend field regression enforces it, per-tier tolerances incl. GLES3/web). Paper/substrate is **screen-locked** — never sampled through the field. Ingress (scroll/roll layouts) is an explicit shader branch writing fresh water; sampler clamp modes cannot express it.
* **MIDI:** SPSC ingest, **exactly one producer thread per instance** (host-synthesized touch MIDI counts as device MIDI). A stateful normalizer (MPE zones via MCM/RPN, ±48 member / ±2 master, wind/classic dialects, dialect auto-detect) emits a device-agnostic vocabulary: VoiceBegin(echo set)/Glide/Press/Slide/Swirl/Migrate/End + GlobalCtl. The marbling simulator never sees raw MIDI. Continuous dims are smoothed + per-frame coalesced; deform passes have a per-frame budget; **continuous controllers drive DELTAS per pass, never absolutes**.
* **One-consumer ownership rules:** `bend_mode` (per-note bend: glide XOR ripple amount — master bend keeps its tine), `slide_mode` (CC74: aux XOR pinch), `press_mode` (0xD0: ink feed XOR Lamb–Oseen swirl; 0xA0 poly pressure → swirl always). Exactly one consumer per dimension; toggles flip cleanly with no stale deltas.
* **Layouts:** pure functions `(layout, params, aspect[, state], x, y) → cell info` — **instance-free probe** callable from any thread (Android touch latency depends on it). Echo sets (Jankó = 3 rows, one voice, shared band/aux, all-or-none budget). Phase 6 adds a `sumi_layout_state_t` snapshot argument (valves/slide); **state changes travel as MIDI CCs** so fingering is recorded/replayed.
* **Play surface (tablets):** touch-centered joystick, radial soft-knee deadband, semitone-exact bend (one grid column = one semitone; ±171 counts at ±48), bipolar Y (up → 0xD0 ink feed, down → 0xA0 swirl), CC74 is stylus-only. LRU-by-release channel allocator with external-occupancy masking. Dual-pipe: loopback full-rate; outbound change-only + per-transport budgets (BLE ≈ 300 msg/s global with per-voice fairness; USB/virtual/network 100 Hz/dim). MCM/RPN0 sent on BOTH pipes (loopback on Play-mode entry; outbound on every sink open/reconnect). **The stylus wake is gesture-only, never MIDI** — a documented invariant: DAW recordings replay notes, not wakes.
* **Media (Phase 6):** engine vs medium split. A medium owns the composite (how the field is READ), palettes, print styling, default bindings. Medium 0 = Sumi (ink bands + washi); medium 1 = the electric medium (strain-glow composite: finite-difference the stored coords for ‖J‖_F). Operators are one shared library across media.

## 3. Working practices
* **One step per session; one platform per step** (machines: Mac = macOS/iOS, Windows box, Linux box = Linux/Android, desktop harness for all core work — core changes prove out on desktop FIRST). Never begin a step while the previous DONE fails. Steps carry explicit spec-section references and credential lists.
* **DONE criteria are the contract:** verifiable, adversarial where it matters (gates proven red before trusted green; byte-log asserts; soak tests; the #33 four-part mass gate for area-preservation claims — strict area conservation is unsatisfiable on a resampled medium, use ink-mass + inversion + no-fabrication + erosion-budget instead).
* **Docs before release lanes** (homepage/privacy/support URLs are hardcoded by casks and stores); web build before docs (live demos ARE the release wasm — no second implementation anywhere). Beta waves gate production; **1.0-style releases promote the final RC the testers held — never a fresh build**. iOS/Android store releases are MANUAL by design (RELEASING.md checklists, audited against reality); desktop+web release via the tag-triggered CI spine + lanes.
* **The Phase-6 ABI event is ONE break:** `medium` param + probe-state + `sumi_set_palette` (+ sound lib is separate). The prebuilt libsumi SDK stays deferred until after it.

## 4. The Phase-6 spec set (current iteration targets)
* **MEDIUM_SPEC.md** — media abstraction + the electric medium. Operators: wave torsion (exact; first brick), Chladni lattice (kick-drift; chord ratios k_x:k_y — harmony as geometry), **viscous multipole burst** (sub-stepped; the author's serendipitous extension of Jaffer's time-integration — elementary for m ≥ 2, dual-time Gaussian core, age knob ℓ² = a² + 4νt; supersedes the algebraic lobe; docs present it modestly, literature-check before any priority wording), spark shear (tri-wave kick-drift; spark strike = exact drop [Joule blast — a monopole displacement field cannot be divergence-free] + rotated quadrupole + shears), Chirikov (ε-scaled drift, delta-K, KAM transition on the mod wheel; erosion soak is the boss gate).
* **INSTRUMENT_SPEC.md** — stateful layouts: trumpet (partials × 3 valve strip buttons, CCs 110–112 proposal), trombone (partials + continuous positional slide widget), Wicki–Hayden, fretboard, theremin.
* **QUALITY_OF_LIFE_SPEC.md** — user palettes (N-stop gradient through the medium's fixed ink-depth/glow curves — identity guardrail), paper/substrate options, presets, print ledger + resolution-independent re-export, **cross-device session replay** (timestamped bytes + params/state + gestures; record on iPad, replay on desktop; re-sounds through Voxo). **Undo is deliberately absent** (author's decision: the dip is the undo).
* **SOUND_SPEC.md** — **Voxo**: Decent Sampler-compatible MPE sampler as a SIBLING C-ABI library (not inside libsumi; not sokol_app). Shares the normalizer as source; fed by the same producer fanned into a second SPSC; miniaudio backend (RtAudio is desktop-only fallback; mobile escapes = AAudio/AVAudioEngine direct). v1: zones/layers/round-robin/loops/ADSR/LP filter/DS MPE bindings + **bus reverb & delay**; compat report per preset; preload-first with advisory gate (`os_proc_available_memory()` on iOS); **foreground-only in v1** — background + disk streaming belong to the deferred sister app **Voxo Dorean** (same library, new tiny shell). Hermite interpolation mandatory for ±48-semitone glides.
* **PHASE5_SPEC.md / ROADMAP_4.md** — the release machinery (kept for reference; Phase 5 is done).
