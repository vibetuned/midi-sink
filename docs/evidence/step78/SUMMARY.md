# Step 78 — The four-lane engine and the ×4 half-band oversampler (2026-10-18)

Voxo **0.18.0**, additive (`DECISIONS_12 #1` the contract before the
refactor, `#2` as shipped; `_work/ROADMAP_6.md` step 78;
`_work/TO_PROJECT_SPEC.md` §13.8 as shipped). The core is frozen: nothing
under `core/` moved.

## What shipped

* **`voxo/src/simd.h`** — four float lanes behind one header: NEON (arm64:
  the Mac, the iPad, the Tab), SSE2 (the x86-64 baseline), WASM SIMD128
  (`-msimd128`), and a scalar fallback performing the same operations in the
  same order (`VOXO_NO_SIMD`: the web gate's reference); `mul_add` /
  `mul_sub` fused where the scalar compiler's contraction fuses, plain under
  `VOXO_NO_FMA`; the helpers forced inline.
* **The Verlet chain in four lanes** (`VerletString::step`; `step_scalar`
  the twin) and **the modal lattice in four lanes** (`lattice_rotate_simd`,
  `lattice_contract_simd`; `lattice_step_scalar` the twin): the scalar
  sub-step's operations in the scalar's order, the cells de-interleaved four
  at a time, the sums in scalar order.
* **The ×4 oversampler** — `voxo_suzu_params_t.oversample` (2 default, 4),
  the cell family's section: the cells, the shears and the SVF at four
  times the rate, decimated through two cascaded 2:1 half-band stages
  (`suzu::HalfBand` over `voxo/src/halfband.h`, generated by
  `tools/halfband_design.py`: 47 taps, Kaiser β 5.65, 64 dB of stopband);
  the ×2 section untouched. **`suzu::prewarp(omega, dt)`.**
* The plumbing: the preset's `oversample` (`presets/SCHEMA.md`), the
  desktop's *Suzu oversample* combo and INI key, the web surface's table
  row, `sw_breaker_trips` on the web surface and the worklet counting a trip
  as a blow-up (the step-75 regression the lab gate found).
* The suite: block 15 at sixteen chains under 6 % on the Release build
  (`RELEASE_BUILD`: a Debug run prints the figure), blocks 29–31.

## The tablets

* **Android (the Pixel 10 Pro emulator, arm64 / NEON, Android 17 — the Tab was not plugged in):** the debug APK with the
  four-lane Voxo, launched with `--es voxoSource suzu --ei suzuPatch <n> --ei voxoSpike 12` on three patches — the Bowed
  string (the lattice and the bow), the Trumpet (the bore and the lips), the Flute (the bore and the jet): 5 261 / 5 266 /
  5 269 callbacks, 0 device XRuns (AAudio), 1 / 0 / 0 proxy XRuns (the first at the first run's start), render max 4.2 /
  2.8 / 2.6 ms of a 20 ms burst, 40 note-ons each, no breaker trip, no crash. `tablets/android_emulator_patch*.txt`,
  the spike CSV of the last run beside.
* **iOS (the iPad):** `build-ios` rebuilt with the four-lane Voxo, the project regenerated through `ios/prepare_release.sh`,
  the app built for a generic device (`ios/build-dd/Build/Products/Debug-iphoneos/midi-sink.app`); the install was refused
  because the iPad had not been unlocked recently (CoreDevice 10003 / RemotePairing 1016) — the device is the author's to
  unlock. The run, once unlocked (bound every call, `DECISIONS_6`'s recipe):
  `xcrun devicectl device install app --device 00008132-000224C00160C01C ios/build-dd/Build/Products/Debug-iphoneos/midi-sink.app`,
  `xcrun devicectl device process launch --device 00008132-000224C00160C01C --terminate-existing com.vibetuned.midi-sink --voxo-source suzu --suzu-patch 0 --voxo-spike 12`,
  then `xcrun devicectl device copy from --device 00008132-000224C00160C01C --domain-type appDataContainer --domain-identifier com.vibetuned.midi-sink --source Documents/voxo_spike.csv --destination <local>`.
